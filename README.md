# Cờ Tỉ Phú — source code đầy đủ

Bản ngày 06/10/2026: bố cục vừa màn hình HD, giá mua và tiền thuê trên từng ô.

## Chạy game
Giải nén và mở dist/index.html bằng Chrome hoặc Edge. Không cần cài đặt.

## Sửa code
- dist/index.html: giao diện HTML.
- dist/style.css: bố cục và màu sắc.
- dist/game.js: luật chơi, máy chơi và tương tác.
- check.cjs: kiểm tra logic; chạy `node check.cjs` nếu đã cài Node.js.

Tiền trong logic dùng đơn vị 10.000 đồng; giao diện hiển thị VNĐ. Game chơi trên cùng thiết bị, hỗ trợ 2–8 người và máy; chưa có lưu ván hoặc chơi online.
